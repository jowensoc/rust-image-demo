# rust-image-demo
A small demo using Rust Image

- Filter - Apply a filter to an image. It rotates the image by x degrees clockwise and then applies an unsharpen mask filter to the image.

# cargo commands
Compile the project and run the demo using the following commands:
```
cargo build
```

```
cargo run
```
